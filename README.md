# Buster Bot

## Спринт 1: User Story 1 — Случайный комплимент

**Как студент, я хочу получать случайный комплимент, чтобы поднять себе настроение.**

---

### Функционал

- Бот отвечает на команду `/compliment`.
- Комплимент выбирается случайным образом из коллекции в `compliments.json`.
- В ответе указывается имя пользователя Telegram.
- Все входящие команды логируются в консоль.

---

### Установка и запуск

1. Шаг 1: клонирование репозитория

```bash
git clone https://github.com/godmozzarella/booster-bot.git
cd booster-bot
```

2. Шаг 2: сборка Maven

```bash
mvn clean install
```

3. Шаг 3: запуск приложения

```bash
mvn spring-boot:run
```
