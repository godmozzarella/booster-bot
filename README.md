# Booster Bot

## Спринт 1: User Story 1 — Случайный комплимент

**Как студент, я хочу получать случайный комплимент, чтобы поднять себе настроение.**

---

### Функционал

- Бот отвечает на команду `/compliment`.
- Комплимент выбирается случайным образом из коллекции в `compliments.json`.
- В ответе указывается имя пользователя Telegram.
- Все входящие команды логируются в консоль.

---

## USER STORY 2: Контекстный буст

**Описание полной работы с тестом, включая TestService, TelegramSendService, CommandHandlerService, handleTestAnswer, клавиатуру и контекстные ответы.**

---

### Функционал

- Реализован сервис TestService для управления логикой теста и вопросов.
- TelegramSendService отвечает за отправку сообщений и клавиатур пользователю.
- CommandHandlerService обрабатывает команды и взаимодействует с пользователем.
- Метод handleTestAnswer обрабатывает ответы пользователя на вопросы теста, сохраняет прогресс и отправляет следующий вопрос.
- Используется интерактивная клавиатура для выбора вариантов ответов.
- Контекстные ответы формируются на основе выбранных пользователем ответов, обеспечивая персонализированный опыт взаимодействия.
- Все действия логируются для удобства отладки и анализа.

### Установка и запуск

1. Шаг 1: клонирование репозитория

```bash
git clone https://github.com/godmozzarella/booster-bot.git
cd booster-bot
```

2. Шаг 2: сборка Maven

```bash
mvn clean install
```

3. Шаг 3: запуск приложения

```bash
mvn spring-boot:run
```
